# LUMIÈRE | Admin Panel

A premium management dashboard for the LUMIÈRE fashion store. Built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Dashboard**: Real-time sales analytics and store overview.
- **Product Management**: Catalog management with inventory tracking.
- **Order Management**: Order processing and status tracking.
- **Customer Insights**: View customer data and purchase history.
- **Responsive Design**: Fully optimized for desktop and tablet views.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Charts**: Recharts (Mocked)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
